# Milestone 7: a week-long soak and chaos test

This milestone follows the topic synthesis `synth/LNX-402/LNX-402-T07.md`. Versions and defaults change; confirm them in current project documents (to verify).

## Goal

Run steady load for seven days and inject planned failures.

## Lessons this milestone relies on

- LNX-307-T07 and T10 (break/fix drills, on-call)
- LNX-307-T08 (OOM and cgroups v2)
- LNX-313-T04 (rolling, blue/green, canary)
- LNX-311-T05 (scheduling and autoscaling)

## Steps

1. Write the hypothesis, load, experiments and abort rules first.
2. Start load and keep it running for the week.
3. Run experiments on the plan: pod kill, node drain, network delay, DNS failure, control plane node loss.
4. Log start and end times and the effect on the hypothesis.
5. Summarise findings and assign each an owner and date.

## Acceptance

- The evidence file passes the check.
- The plan predates the run (commit dates).
- Each finding has an owner.
