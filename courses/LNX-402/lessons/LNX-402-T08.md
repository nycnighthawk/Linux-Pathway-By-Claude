# Milestone 8: a scale test with one hundred or more nodes

This milestone follows the topic synthesis `synth/LNX-402/LNX-402-T08.md`. Versions and defaults change; confirm them in current project documents (to verify).

## Goal

Find the first bottleneck of the platform at one hundred nodes or more.

## Lessons this milestone relies on

- LNX-311-T12 (hundreds of nodes, long-lived upgrades)
- LNX-312-T12 (MTU, encapsulation overhead, throughput)
- LNX-307-T09 (reliable benchmarking)
- LNX-307-T05 (perf and eBPF tools)

## Steps

1. Decide real or simulated nodes and state what that leaves untested.
2. Grow the cluster in at least three steps, measuring API latency, scheduling rate and etcd size at each.
3. Watch the monitoring stack itself; note when it struggles.
4. Change one thing to relieve the first bottleneck and measure again.
5. Write down versions and settings so the test can be repeated.

## Acceptance

- The evidence file passes the check.
- At least three sizes were measured.
- The honest limits of the method are written down.
