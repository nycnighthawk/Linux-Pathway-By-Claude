# Milestone 6: the same platform on managed Kubernetes

This milestone follows the topic synthesis `synth/LNX-402/LNX-402-T06.md`. Versions and defaults change; confirm them in current project documents (to verify).

## Goal

Bring the platform to a managed cluster with a small overlay and compare the result.

## Lessons this milestone relies on

- LNX-311-T11 (managed Kubernetes: EKS, AKS, GKE)
- LNX-306-T05 and T10 (OpenTofu, cloud provisioning)
- LNX-313-T07 (GitOps)
- LNX-312-T06 (Gateway API)

## Steps

1. Create a budget alert, then the managed cluster with infrastructure code and workload identity.
2. Bootstrap the same GitOps controller and point it at the same repository with a provider overlay.
3. Run your check suite unchanged; list what failed and why.
4. Remove duplicated add-ons or document why they stay.
5. Record cost per hour, then tear everything down and list by tag.

## Acceptance

- The evidence file passes the check.
- The overlay holds only provider-specific settings and each is explained.
- No static cloud key is in Git and the teardown listing is empty.
