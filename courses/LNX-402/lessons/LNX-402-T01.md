# Milestone 1: two kubeadm clusters, Cilium and the Gateway API

This milestone follows the topic synthesis `synth/LNX-402/LNX-402-T01.md`. Versions and defaults change; confirm them in current project documents (to verify).

## Goal

Build two separate clusters on virtual machines and expose a test application through a gateway.

## Lessons this milestone relies on

- LNX-311-T01 and T02 (architecture, kubeadm on VMs, HA design)
- LNX-312-T03 and T05 (CNI comparison, eBPF datapath and Hubble)
- LNX-312-T06 (Ingress and Gateway API)
- LNX-308-T01 and T02 (libvirt VMs, templates)
- LNX-305-T01 to T03 (automating the build)

## Steps

1. Choose distinct cluster names, endpoints, pod ranges and service ranges and write them in one inventory.
2. Create the VMs from one template with cloud-init and render a kubeadm configuration per cluster.
3. Install Cilium with kube-proxy replacement; check node status and the Cilium status command.
4. Install the Gateway API definitions, create a gateway that accepts routes only from selected namespaces, and attach a route for a test app.
5. Write one verification script and run it on both clusters.

## Acceptance

- The grader passes on your configuration and gateway files.
- Both clusters report all nodes Ready and the test hostname answers through the gateway.
- A rebuild from the repository gives the same result.
