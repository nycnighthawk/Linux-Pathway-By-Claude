# Milestone 2: GitOps for platform and applications with Argo CD

This milestone follows the topic synthesis `synth/LNX-402/LNX-402-T02.md`. Versions and defaults change; confirm them in current project documents (to verify).

## Goal

Move every change after bootstrap to Git and show it reconciling on both clusters.

## Lessons this milestone relies on

- LNX-313-T07 (GitOps with Argo CD or Flux)
- LNX-311-T08 (Helm and Kustomize)
- LNX-305-T04 (secrets with Vault)
- LNX-303-T09 (secrets tooling)

## Steps

1. Bootstrap the controller once and create a root application with automated sync, prune and self-heal.
2. Use an ApplicationSet to generate an application per cluster and component, with a pinned revision, not a moving branch head.
3. Order installation with sync waves: definitions first, controllers, then applications.
4. Remove any plain-text secret from Git and use an external or sealed secret.
5. Show a rollback by reverting a commit and a drift correction by changing a live object by hand.

## Acceptance

- The grader passes on your layout files.
- A change made only by a Git commit reaches both clusters in the order you planned.
- The repository history contains no secret.
