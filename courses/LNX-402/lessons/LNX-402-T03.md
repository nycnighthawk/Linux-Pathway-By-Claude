# Milestone 3: version upgrade and etcd restore drill

This milestone follows the topic synthesis `synth/LNX-402/LNX-402-T03.md`. Versions and defaults change; confirm them in current project documents (to verify).

## Goal

Rehearse a one-minor upgrade and a restore from an etcd snapshot after a deliberate failure.

## Lessons this milestone relies on

- LNX-311-T03 (cluster upgrades, drain and cordon)
- LNX-311-T04 (etcd backup and restore)
- LNX-311-T10 (troubleshooting)
- LNX-311-T12 (long-lived upgrades)

## Steps

1. Write the plan as code: snapshot, plan, first control plane node, other control plane nodes, then workers one at a time.
2. Check for deprecated APIs in your manifests before starting.
3. Take and verify a snapshot and copy it off the node.
4. Run the upgrade on the second cluster and record timestamps.
5. Delete a namespace on purpose, restore from the snapshot, and state the recovery point you actually got.

## Acceptance

- The grader passes on your plan function.
- Node versions and workload health are verified after each stage.
- The restore drill note states what was lost between snapshot and failure.
