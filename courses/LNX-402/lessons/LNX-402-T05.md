# Milestone 5: observability with Prometheus, OpenTelemetry and Hubble

This milestone follows the topic synthesis `synth/LNX-402/LNX-402-T05.md`. Versions and defaults change; confirm them in current project documents (to verify).

## Goal

Give the platform metrics, traces and network flows, and alerts that catch silent failure.

## Lessons this milestone relies on

- LNX-307-T03 (Prometheus, Grafana, alerting)
- LNX-313-T09 (Prometheus metrics and OpenTelemetry)
- LNX-312-T05 (Hubble)
- LNX-307-T01 (USE and RED methods)

## Steps

1. Deploy Prometheus and its rules from Git; provision dashboards as code.
2. Deploy an OpenTelemetry collector and instrument one app so a request produces a trace.
3. Enable Hubble and use it to prove a policy denial.
4. Write alerts for error ratio, missing targets and expiring certificates, with a waiting time, severity and runbook link each.
5. Cause a fault and walk from alert to trace to flow.

## Acceptance

- The grader passes on your rules file.
- One incident is explained from all three signals.
- An alert fires when a scrape target is removed.
