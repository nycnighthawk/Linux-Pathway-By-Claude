# Milestone 3: a pinned hugepage-backed VM that meets a latency target

This milestone follows the topic synthesis `synth/LNX-405/LNX-405-T03.md`. Versions and defaults change; confirm them in current project documents (to verify).

## Goal

Tune a VM until its worst-case latency meets a target set in advance.

## Lessons this milestone relies on

- LNX-315-T03 (NUMA, pinning, hugepages, IOThreads)
- LNX-307-T09 (reliable benchmarking)
- LNX-307-T05 (perf and eBPF)
- LNX-320-T13 (NUMA and cache-effect measurement)

## Steps

1. Write the target first and measure the default VM with a latency tool under load.
2. Isolate host cores, move interrupts off them and place everything on one NUMA node.
3. Back guest memory with hugepages and pin each vCPU and the I/O threads.
4. Change one setting at a time; keep a table of worst-case results.
5. Run the final configuration for at least an hour under load and check for firmware interrupts.

## Acceptance

- The evidence file passes the check.
- The target predates the first measurement.
- You state whether the target was met.
