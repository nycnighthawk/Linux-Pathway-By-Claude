# Milestone 5: a test or feature sent for review

This milestone follows the topic synthesis `synth/LNX-405/LNX-405-T05.md`. Versions and defaults change; confirm them in current project documents (to verify).

## Goal

Contribute a small, correct test to QEMU or the KVM selftests and answer review.

## Lessons this milestone relies on

- LNX-332-T08 (testing KVM: kvm-unit-tests and selftests)
- LNX-332-T06 (QEMU device models and qtest)
- LNX-332-T12 (upstreaming to KVM and QEMU)
- LNX-330-T06 (patch mail and list etiquette)

## Steps

1. Find a gap in the existing tests and read the project's submission guide and style rules.
2. Write the test; show it failing without the fix or feature and passing with it.
3. Run it on more than one architecture and make it skip cleanly when unsupported.
4. Send the series, answer each comment inline and send a revised version with a changelog.
5. Record every version and archive link.

## Acceptance

- The evidence file passes the check.
- Every comment has an answer.
- The test is deterministic across ten runs.
