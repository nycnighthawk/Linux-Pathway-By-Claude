# Milestone 4: VFIO passthrough of a real device

This milestone follows the topic synthesis `synth/LNX-405/LNX-405-T04.md`. Versions and defaults change; confirm them in current project documents (to verify).

## Goal

Give a spare PCI device to a guest and get it back.

## Lessons this milestone relies on

- LNX-315-T01 and T02 (VFIO PCI passthrough and IOMMU groups, SR-IOV)
- LNX-308-T03 (VM networking, for comparison with virtio)
- LNX-332-T09 (interrupt virtualisation)
- LNX-330-T09 (kernel messages and debugging)

## Steps

1. Enable the IOMMU in firmware and on the kernel command line; confirm in the kernel log.
2. List IOMMU groups and choose a device whose group holds only itself or its bridge.
3. Bind the device to vfio-pci and start a guest with it assigned.
4. Check in the guest that the device appears, its driver loads and it does real work; reboot the guest and check reset.
5. Return the device to the host and record how.

## Acceptance

- The evidence file passes the check.
- No isolation was weakened, or the reason is written down.
- The host is back to its original state.
