# Milestone 6: a VM-escape CVE analysis and mitigations write-up

This milestone follows the topic synthesis `synth/LNX-405/LNX-405-T06.md`. Versions and defaults change; confirm them in current project documents (to verify).

## Goal

Explain a public, fixed escape vulnerability and what defenders should do.

## Lessons this milestone relies on

- LNX-332-T06 (QEMU device models, where many escapes arise)
- LNX-204-T04 and T05 (SELinux and AppArmor)
- LNX-204-T11 (CVE and errata triage)
- LNX-314-T08 (gVisor and Kata RuntimeClass, as sandbox designs)
- LNX-308-T01 (libvirt and sVirt)

## Steps

1. Choose a public vulnerability that is fixed and well documented.
2. Describe the component, weakness class, what the guest controls and the impact without exploit detail.
3. Compute the severity from the vector and explain whether the score fits real deployments.
4. List mitigations in layers (patch, remove, confine, run unprivileged) and a detection step.
5. State one design lesson and cite at least three sources from two publishers.

## Acceptance

- The grader passes on the write-up.
- No exploit code or payload appears.
- Mitigations include one that does not depend on patching.
