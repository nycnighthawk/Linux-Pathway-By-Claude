# Milestone 2: one image pipeline for three platforms

This milestone follows the topic synthesis `synth/LNX-405/LNX-405-T02.md`. Versions and defaults change; confirm them in current project documents (to verify).

## Goal

Build one image and deliver it to libvirt, VirtualBox and KubeVirt with identical smoke tests.

## Lessons this milestone relies on

- LNX-315-T06 to T08 (VirtualBox administration, VirtualBox on KVM, image pipelines)
- LNX-315-T09 (KubeVirt)
- LNX-308-T02 (templates, snapshots, virt-customize)
- LNX-306-T03 and T04 (cloud-init, Packer)

## Steps

1. Build one qcow2 source image with a first-boot agent and record its checksum.
2. Convert for VirtualBox; package a container disk for KubeVirt with the right owner and path.
3. Provide the same cloud-init seed to all three.
4. Run the same smoke test everywhere: login, kernel version, image checksum from inside the guest.
5. Pin every tag and publish the checksums.

## Acceptance

- The grader passes on the pipeline description.
- All three platforms report the same image checksum.
- No target uses a floating tag.
