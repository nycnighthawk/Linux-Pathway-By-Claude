# Milestone 1: a VMM that boots Linux with virtio devices

This milestone follows the topic synthesis `synth/LNX-405/LNX-405-T01.md`. Versions and defaults change; confirm them in current project documents (to verify).

## Goal

Write a small VMM in C or Rust that boots a Linux guest to a shell and test it in CI.

## Lessons this milestone relies on

- LNX-332-T01 to T04 (hardware virtualisation, the KVM API, a Rust VMM, virtio from scratch)
- LNX-332-T05 (vhost and vhost-user)
- LNX-332-T08 (testing KVM)
- LNX-308-T01 and T04 (KVM basics, virtio)
- LNX-320-T03 and T07 (epoll, IPC for the device threads)

## Steps

1. Plan guest memory, the MMIO gap and device windows in one function, with validation.
2. Create the VM, map memory, load the kernel and initrd, start one vCPU and handle serial output.
3. Add virtio-blk and virtio-net with validation of every descriptor chain.
4. Write a CI job that boots a tiny guest, waits for a console marker, reads a sector pattern and exits.
5. Add malformed-chain tests and run them under sanitizers or with Rust checks.

## Acceptance

- The grader passes on the layout model.
- CI boots the guest and fails on a missing marker.
- A malformed descriptor chain is refused, not trusted.
