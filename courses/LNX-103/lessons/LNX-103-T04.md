## Swap in practice

```bash
mkswap -L swap0 /dev/vg0/swap
swapon /dev/vg0/swap            # -p 10 sets the priority
swapon --show                   # or: cat /proc/swaps
swapoff /dev/vg0/swap
echo 'UUID=<uuid>  none  swap  defaults,pri=10  0 0' >> /etc/fstab
```

Priorities: higher is used first, equal priorities are used round-robin. A swap area becomes a `.swap` unit at boot.

## A swap file

```bash
dd if=/dev/zero of=/swapfile bs=1M count=2048
chmod 600 /swapfile
mkswap /swapfile && swapon /swapfile
echo '/swapfile none swap defaults 0 0' >> /etc/fstab
```

The kernel writes to the file's blocks directly, so the file must have **no holes**: not `truncate`, not a sparse copy.
`fallocate` is fine on ext4 and on XFS since kernel 4.18. On Btrfs the file needs no-COW (`btrfs filesystem
mkswapfile`). Swap over NFS is unreliable. For hibernation to a file, boot with `resume=UUID=` and `resume_offset=`
(`filefrag -v /swapfile` shows the first physical block).

## zram and zswap

```bash
zramctl --find --size 4G --algorithm zstd      # prints /dev/zram0
mkswap /dev/zram0 && swapon -p 100 /dev/zram0
```

```ini
# /etc/systemd/zram-generator.conf
[zram0]
zram-size = ram / 2
compression-algorithm = zstd
swap-priority = 100
```

zram is a compressed block device in RAM used as swap. zswap is a compressed cache in front of a real swap device
(`zswap.enabled=1` on the kernel command line). The `/sys/block/zram0/` files show `disksize`, `comp_algorithm` and
`mm_stat`.

## Tuning and diagnosis

`vm.swappiness` (default 60) biases between dropping file cache and swapping anonymous memory. Persist it in
`/etc/sysctl.d/`. The signal that matters is **paging activity**, not swap used: `vmstat 1` columns `si` and `so`,
`/proc/pressure/memory`. Encrypt swap if it can hold secrets (`/etc/crypttab` with a random key) or use zram only.

## Common failure patterns

| Symptom | Likely cause | First thing to check |
|---|---|---|
| `swapon: skipping - it appears to have holes` | file made with truncate or cp | recreate with `dd` |
| Insecure permissions warning | mode too open | `chmod 600` |
| Machine slow, swap "used" is small | thrashing on a little swap | `vmstat 1`, memory pressure |
| Hibernate fails with swap file | wrong resume offset | `filefrag -v`, kernel arguments |
