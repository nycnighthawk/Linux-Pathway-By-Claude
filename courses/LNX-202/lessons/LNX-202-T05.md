## Structure

Kea runs one daemon per protocol with its own file and service: `/etc/kea/kea-dhcp4.conf` (`kea-dhcp4`) and `kea-dhcp6.conf` (`kea-dhcp6`); the dynamic DNS daemon is separate, and so is the control agent in older releases; Kea 3.x deprecates it because the daemons can serve HTTP commands themselves (check the release notes for the version that removes it, to verify). The file is JSON, and Kea's parser also accepts `//` and `#` comments.

```json
{ "Dhcp4": {
    "interfaces-config": { "interfaces": [ "eth1" ] },
    "lease-database": { "type": "memfile", "persist": true },
    "valid-lifetime": 3600, "renew-timer": 900, "rebind-timer": 1800,
    "subnet4": [ {
      "id": 1, "subnet": "192.0.2.0/24",
      "pools": [ { "pool": "192.0.2.100 - 192.0.2.199" } ],
      "option-data": [ { "name": "routers", "data": "192.0.2.1" } ],
      "reservations": [ { "hw-address": "52:54:00:aa:bb:01", "ip-address": "192.0.2.20" } ]
    } ]
} }
```

Test with `kea-dhcp4 -t FILE` before `systemctl reload kea-dhcp4`. A relayed request selects the subnet that contains the relay address (giaddr); a direct request uses the interface address.

## Leases

A lease is the period a client may use an address. The default `memfile` store writes `/var/lib/kea/kea-leases4.csv`; do not edit it by hand, because Kea keeps the data in memory. MySQL and PostgreSQL back ends serve shared or reporting needs. A client renews at the renew timer (T1) with its server, rebinds to any server at T2 and must stop at expiry. Hook libraries add `lease_cmds` and `host_cmds` (API), `stat_cmds`, `ha` (high availability) and `flex_id`.

```bash
journalctl -u kea-dhcp4 -f
tcpdump -ni eth1 port 67 or port 68
```

## Common failure patterns

| Symptom | Likely cause | First thing to check |
|---|---|---|
| Reload does nothing | syntax error such as a missing comma | `kea-dhcp4 -t` |
| Clients behind a relay get no answer | no subnet contains the relay address | subnet definitions, `giaddr` in a capture |
| Pool exhausted | long leases on a busy network | `valid-lifetime`, lease file |
| Reserved address handed to someone else | reservation inside the pool | move it outside or use out-of-pool mode |
