## Bonds

A bond joins ports into one interface. `active-backup` keeps one port live and needs no switch support; `802.3ad` negotiates LACP and needs an LACP group on the peer. Both ends of an LACP bond choose outgoing ports with their own transmit hash policy: `layer2`, `layer2+3` or `layer3+4`. A hash picks a port per flow, so one TCP stream uses one port.

```bash
ip link add bond0 type bond mode 802.3ad miimon 100 lacp_rate fast xmit_hash_policy layer3+4
ip link set eth1 down; ip link set eth1 master bond0
ip link set eth2 down; ip link set eth2 master bond0
ip link set bond0 up; ip link set eth1 up; ip link set eth2 up
cat /proc/net/bonding/bond0     # mode, hash policy, per-port state, Aggregator ID, partner MAC
```

Ports that show different Aggregator IDs did not form one bundle. In systemd-networkd the same settings are `Mode=`, `TransmitHashPolicy=`, `LACPTransmitRate=` and `MIIMonitorSec=`, and monitoring is off until you set it.

## VLANs and bridges

```bash
ip link add link bond0 name bond0.20 type vlan id 20
ip link add br0 type bridge vlan_filtering 1
ip link set bond0 master br0
bridge vlan add dev bond0 vid 20                    # tagged on the uplink
bridge vlan add dev tap-vm1 vid 20 pvid untagged    # access port for a guest
bridge vlan show; bridge fdb show br br0
```

`pvid` assigns untagged ingress frames to a VLAN, `untagged` strips the tag on egress. Ports without those flags are trunk ports. The default VLAN 1 stays on every port until you delete it. A VLAN child cannot have a larger MTU than its parent, and the tag adds four bytes.

## Common failure patterns

| Symptom | Likely cause | First thing to check |
|---|---|---|
| Second cable carries nothing | hash puts every flow on one port | `xmit_hash_policy`, number of flows |
| Bond shows two Aggregator IDs | switch side is static or not LACP | switch port-channel mode, `/proc/net/bonding/bond0` |
| Guest cannot reach the gateway | tap port is in the wrong VLAN | `bridge vlan show` |
| Frames loop and the network collapses | two bridge ports on one segment without STP | `bridge link`, STP state |
