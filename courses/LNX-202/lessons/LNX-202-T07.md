## WireGuard

Each node has a key pair and exchanges only public keys. `AllowedIPs` is both the routing table (where packets for a destination go) and the access list (which inner source addresses a peer may use).

```bash
umask 077; wg genkey | tee priv.key | wg pubkey > pub.key
```

```ini
[Interface]
Address = 10.0.0.1/24
ListenPort = 51820
MTU = 1420
PrivateKey = <contents of priv.key>

[Peer]
PublicKey = <key of the far peer>
AllowedIPs = 192.168.20.0/24, 10.0.0.2/32
Endpoint = 203.0.113.102:51820
PersistentKeepalive = 25
```

`wg-quick up ./wg0.conf` creates the interface and routes (`systemctl enable --now wg-quick@wg0` makes it persistent); `wg show` prints peers, endpoints, last handshake and counters. A peer without a handshake never completed the exchange. The endpoint is learned from the last valid packet, so roaming works; keepalives keep a NAT mapping open. Open the UDP listen port in the firewall.

## IPsec

IPsec encrypts with ESP (IP protocol 50) after IKE negotiates keys on UDP 500 and 4500. Tunnel mode wraps the whole packet (VPNs); transport mode protects the payload (host to host). On Linux the kernel XFRM framework applies policies and keys, and Libreswan or strongSwan negotiates them.

```
conn site-b
    left=198.51.100.1
    leftsubnet=192.168.10.0/24
    right=203.0.113.2
    rightsubnet=192.168.20.0/24
    authby=secret
    keyexchange=ikev2
    auto=start
```

```bash
ipsec auto --add site-b; ipsec auto --up site-b
ipsec trafficstatus; ip xfrm state; ip xfrm policy
tcpdump -ni eth0 esp or udp port 500 or udp port 4500
```

For larger deployments use certificates (`authby=rsasig`). Both ends must agree on IKE version, algorithms, subnets and keys.

## Common failure patterns

| Symptom | Likely cause | First thing to check |
|---|---|---|
| Tunnel up, large transfers stall | MTU too large for the path | `ping -M do -s SIZE`, lower the interface MTU |
| `wg show` has no handshake | wrong key, endpoint or blocked UDP port | keys, firewall, `Endpoint` |
| `ipsec up` repeats retransmissions | firewall drops IKE | `tcpdump` on UDP 500 and 4500 |
| Traffic for a LAN goes nowhere | `AllowedIPs` lacks the prefix | peer section of the config |
