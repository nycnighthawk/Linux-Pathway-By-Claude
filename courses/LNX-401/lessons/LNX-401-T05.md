# Milestone 5: the baseline in a public cloud

This milestone follows the topic synthesis `synth/LNX-401/LNX-401-T05.md`. Product versions and defaults change; confirm them in current vendor documents (to verify).

## Goal

Deploy the same baseline in a cloud and remove it again.

## Lessons this milestone relies on

- LNX-306-T03 to T05 and T10 (cloud-init, Packer, OpenTofu, cloud provisioning)
- LNX-305-T03 (roles)
- LNX-204-T06 (firewall)
- LNX-303-T09 (secrets tooling)
- LNX-307-T03 (monitoring)

## Steps

1. Create a budget alert first. Tag every resource with owner and expiry.
2. Split code into a provider module and the same roles you used on premises.
3. Join instances to the estate directory over a private path; check the time source.
4. Scan the baseline in the cloud and on premises and compare.
5. Tear down, then list resources by tag to prove nothing is left.

## Acceptance

- The evidence file passes the check.
- No key or password is in the repository history.
- The teardown listing is empty.
