# Milestone 1: IdM, Samba AD, six servers, repository and monitoring

This milestone follows the topic synthesis `synth/LNX-401/LNX-401-T01.md`. Product versions and defaults change; confirm them in current vendor documents (to verify).

## Goal

Describe and build the baseline estate from one repository.

## Lessons this milestone relies on

- LNX-301-T01 to T04 (directory basics, Kerberos, SSSD, joining Samba AD)
- LNX-301-T06 and T07 (IdM replicas, trust to AD)
- LNX-302-T03 and T05 (Samba AD replication, DNS and time)
- LNX-305-T01 to T03 (inventory, playbooks, roles)
- LNX-304-T04 and T05 (repository and dated snapshots)
- LNX-307-T03 (Prometheus and alerting)
- LNX-308-T01 (virtual machines for the lab)
- LNX-202-T04 (DNS), LNX-204-T06 (firewall baseline)

## Steps

1. Write `estate.yaml`: realms, subnet, trust, six mixed members, two IdM servers, one Samba DC, a repository host and a monitoring host.
2. State the stage order and why: DNS and time, directories, trust, repository, clients, exporters, monitoring.
3. Build it on your lab virtual machines with your configuration management roles. Use a secrets tool for join credentials.
4. Write one verification play that asks real questions: ticket login over SSH, repository snapshot served, every target up.
5. Run the grader and fix any inconsistency it finds before you build.

## Acceptance

- The grader passes on `estate.yaml`.
- A clean rebuild from the repository reaches the same verification result.
- Every host appears once in monitoring, and an alert fires if the target count drops below the inventory count.
