# Milestone 4: thirty days of operations

This milestone follows the topic synthesis `synth/LNX-401/LNX-401-T04.md`. Product versions and defaults change; confirm them in current vendor documents (to verify).

## Goal

Operate the estate for a month and learn from it.

## Lessons this milestone relies on

- LNX-307-T01 (USE/RED methods, runbooks)
- LNX-307-T03 and T04 (alerting, central logging)
- LNX-307-T07 and T10 (break/fix drills, production on-call)
- LNX-304-T10 (multi-week fleet rollouts)
- LNX-303-T11 (long-term compliance drift)

## Steps

1. Write service objectives before day one (login success, repository availability, patch lag).
2. Keep a daily log: alerts fired, alerts that should have fired, manual actions.
3. Run at least four patch rings, one restore test and one access review.
4. Write a handover note each week as if another person takes over.
5. At the end, summarise and compute the service levels from monitoring data.

## Acceptance

- The evidence file passes the check.
- The objectives were written before the run (show the commit date).
- At least one repeated manual task became code.
