This lesson follows the topic synthesis `synth/LNX-102/LNX-102-T09.md`, which carries the sources and the history.

## What you will be able to do

- List, activate and verify a TuneD profile.
- Write a custom profile that includes another and overrides chosen settings.
- Decide when a profile is better than hand-edited sysctl files.

## What TuneD does

TuneD is a daemon (`tuned.service`) that applies a named bundle of system settings: sysctl values, CPU governor, disk
parameters, kernel boot arguments and more. It can also change settings when conditions change. Profiles ship in
`/usr/lib/tuned/<name>/tuned.conf`; your own go in `/etc/tuned/<name>/tuned.conf`.

```bash
tuned-adm list                  # available profiles
tuned-adm active                # current profile
tuned-adm recommend             # what fits this hardware
tuned-adm profile lab-web       # activate
tuned-adm verify                # compare running settings with the profile
tuned-adm off
```

Typical shipped profiles are `balanced`, `throughput-performance`, `latency-performance`, `network-latency` and
`virtual-guest`; the list differs between releases.

## Anatomy of a profile

```ini
[main]
summary=Web server tuning
include=throughput-performance

[sysctl]
vm.swappiness=10
vm.dirty_ratio=15

[cpu]
governor=performance
```

`include=` starts from another profile; your sections then override it. Each plugin has its own section (`[sysctl]`,
`[cpu]`, `[disk]`, `[bootloader]`, `[script]`). Changes to a profile apply after `tuned-adm profile name` or a service
restart.

## Profile or sysctl file?

| Situation | Choice |
|---|---|
| One or two kernel parameters | `/etc/sysctl.d` file |
| A tested bundle across many hosts, with CPU and disk settings | TuneD profile |
| Compliance baseline forbids extra daemons | no TuneD, plain files |

TuneD and a hand-written sysctl file can fight; decide which owns a parameter.

## Common failure patterns

| Symptom | Likely cause | First thing to check |
|---|---|---|
| Profile not found | Wrong directory or file name | `ls /etc/tuned/name/tuned.conf` |
| Settings revert | Another tool owns them | `tuned-adm verify`, sysctl files |
| Profile ignored after edit | Not re-applied | `tuned-adm profile name` |
| No effect on a VM | Hypervisor limits the knob | `tuned-adm recommend` |
