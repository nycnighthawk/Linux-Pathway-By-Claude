# Processes, signals, priority and job control

This lesson follows the topic synthesis `synth/LNX-102/LNX-102-T02.md`, which carries the sources and the history.

## What you will be able to do

- List processes and read PID, PPID, state, nice value and the controlling terminal.
- Send the right signal, and say why `SIGKILL` is a last resort.
- Change priority with `nice` and `renice`, and use shell job control.

## Looking at processes

```bash
ps -eo pid,ppid,stat,ni,pri,cmd --sort=-%cpu | head
ps -o pid,stat,wchan:20,cmd -p 1234
pgrep -a sshd            # list matches; pkill sends a signal to them
```

Common state letters in `STAT`: `R` running, `S` interruptible sleep, `D` uninterruptible sleep (usually waiting on I/O,
cannot be killed until it returns), `T` stopped, `Z` zombie (finished, waiting for its parent to call `wait`). A zombie
is not killable; fix or end the parent. `/proc/PID/status`, `cmdline` and `fd/` hold the raw data that `ps` and `lsof`
read.

## Signals

| Signal | Number | Default | Use |
|---|---|---|---|
| `SIGHUP` | 1 | terminate | terminal closed; many daemons reread config |
| `SIGINT` | 2 | terminate | Ctrl-C |
| `SIGTERM` | 15 | terminate | polite request, can be caught; the default of `kill` |
| `SIGKILL` | 9 | terminate | cannot be caught or ignored; no cleanup |
| `SIGSTOP` | 19 | stop | cannot be caught; `SIGCONT` (18) resumes |
| `SIGTSTP` | 20 | stop | Ctrl-Z |

Numbers shown are the x86 and Arm values; use names in scripts. `kill -l` lists them. Send `SIGTERM` first, wait, then
`SIGKILL`. `kill -STOP` and `kill -CONT` freeze and thaw a process without losing its state.

## Priority

The nice value runs from -20 (greedy) to 19 (polite); the default is 0. Only root can lower it below the current value.

```bash
nice -n 10 ./batch-job &
renice -n 5 -p 1234
renice -n 15 -u backup       # all processes of a user
```

Nice affects only the CPU scheduler's share among competing normal tasks. For I/O use `ionice -c3` (idle class); for hard
limits use cgroups or `systemd-run -p CPUQuota=20%`.

## Job control in an interactive shell

`cmd &` starts in the background, Ctrl-Z stops the foreground job, `jobs` lists, `bg %1` continues in the background,
`fg %1` brings it back. `nohup cmd &` or `disown` lets a job outlive the terminal; `tmux` or a systemd unit is better for
anything long.

## Common failure patterns

| Symptom | Likely cause | First thing to check |
|---|---|---|
| `kill` has no effect | Process in `D` state, or handler ignores TERM | `ps -o stat,wchan`, then `strace -p` |
| Zombies accumulate | Parent never waits | `ps -eo pid,ppid,stat | awk '$3 ~ /Z/'` |
| `renice` refused | Lowering nice needs root | Run as root or raise the value |
| Job dies at logout | Hangup signal | `nohup`, `disown`, or a unit |
