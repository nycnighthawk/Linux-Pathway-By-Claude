## Two logging systems that cooperate

`systemd-journald` collects messages from services (stdout and stderr), the kernel and `syslog()` into a binary journal.
`rsyslog` is a classic text-file daemon that can also read from journald. Many servers keep both: the journal for
queries, files for forwarding and compliance.

```bash
journalctl -u nginx.service --since "1 hour ago" -p warning
journalctl -b -1            # previous boot (needs persistent storage)
journalctl -f               # follow;  --disk-usage, --vacuum-size=200M
```

The journal is only in memory (`/run/log/journal`) unless storage is persistent. Set it in a drop-in such as
`/etc/systemd/journald.conf.d/50-lab.conf`:

```ini
[Journal]
Storage=persistent
SystemMaxUse=200M
MaxRetentionSec=1month
```

## rsyslog rules

A rule is a selector `facility.priority` and an action. Drop-ins live in `/etc/rsyslog.d/*.conf`.

```
local6.*    /var/log/myapp.log
auth,authpriv.*   /var/log/secure
*.info;mail.none  /var/log/messages
```

Facilities are fixed names (`auth`, `authpriv`, `cron`, `daemon`, `kern`, `mail`, `local0` to `local7`) and priorities run
from `emerg` down to `debug`. A leading `-` before the file name disables sync after every line. Restart with
`systemctl restart rsyslog`; test with `logger -p local6.info "hello"`.

## logrotate

```
/var/log/myapp.log {
    weekly
    rotate 8
    compress
    missingok
    notifempty
    create 0640 root adm
}
```

`logrotate -d file` is a dry run, `logrotate -f -s state file` forces one rotation with a private state file. The state
lives in `/var/lib/logrotate/`; the daily run is a cron job or `logrotate.timer`. If a daemon keeps the old file open,
add a `postrotate` script that signals it, or use `copytruncate` as a lossy fallback. `logrotate` skips configs that
are writable by others.

## Common failure patterns

| Symptom | Likely cause | First thing to check |
|---|---|---|
| Journal empty after reboot | Storage not persistent | `ls /var/log/journal`, `Storage=` |
| Logs rotate but the app keeps writing the old file | No reload signal | `postrotate`, `lsof \| grep deleted` |
| Rule has no effect | Facility mismatch or no restart | `logger -p`, `systemctl status rsyslog` |
| Disk full of logs | No size limit | `journalctl --disk-usage`, `rotate`, `maxsize` |
