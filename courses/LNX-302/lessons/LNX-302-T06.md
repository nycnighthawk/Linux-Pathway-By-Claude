# PowerShell 7 and OpenSSH on Windows

This lesson follows the topic synthesis `synth/LNX-302/LNX-302-T06.md`, which carries the sources and the history.

## What you will be able to do

- Add a PowerShell remoting subsystem and connect with `Enter-PSSession -HostName` from Linux.
- Explain why key login silently falls back to a password on Windows, and fix the ACL.
- Choose between SSH and WinRM transports for a task.

## Two gaps, one answer

Windows historically offered WinRM on ports 5985 and 5986 and a shell tied to .NET Framework. Windows PowerShell 5.1 ships with the OS and is not developed further. PowerShell 7 (`pwsh`) is cross-platform, installed side by side with 5.1, and numbered separately; 7.6 is the long-term-support line built on .NET 10. OpenSSH ships with Windows as an optional capability. Together they give one port, one credential type and one shell for both operating systems.

## The server

```powershell
Get-WindowsCapability -Online -Name 'OpenSSH.Server*' | Add-WindowsCapability -Online
Set-Service sshd -StartupType Automatic
Start-Service sshd
```

Configuration is `C:\ProgramData\ssh\sshd_config`; test with `sshd -T`; logs are in the `OpenSSH/Operational` event channel. Four differences from Linux:

1. **Default shell**: `cmd.exe`. Set the `DefaultShell` string under `HKLM:\SOFTWARE\OpenSSH` to the full path, for PowerShell 7 `C:\Program Files\PowerShell\7\pwsh.exe`. It applies to the server only.
2. **Administrator keys**: members of the local Administrators group use `C:\ProgramData\ssh\administrators_authorized_keys`, selected by a `Match Group administrators` block. The file must be writable only by SYSTEM and Administrators: `icacls <file> /inheritance:r /grant 'Administrators:F' /grant 'SYSTEM:F'`. Otherwise the server ignores it.
3. **Names**: `ssh user@acme.example@host` or `'ACME\user'@host` for domain accounts.
4. **Files**: `scp`/`sftp` paths look like `/C:/Users/alice/x.txt`; `chmod` is cosmetic because ACLs rule.

## PowerShell remoting over SSH

Add to `sshd_config`, using the short path form because spaces break the directive, then restart `sshd`:

```text
Subsystem powershell C:/Progra~1/PowerShell/7/pwsh.exe -sshs -NoLogo -NoProfile
```

From any machine with `pwsh` and `ssh`:

```powershell
Enter-PSSession -HostName win01.acme.example -UserName alice -KeyFilePath ~/.ssh/id_ed25519
$s = New-PSSession -HostName win01.acme.example -UserName alice
Invoke-Command -Session $s -ScriptBlock { Get-Service sshd }
```

`-HostName` selects SSH; `-ComputerName` selects WinRM. Results arrive as deserialised property bags without methods. SSH remoting has no Kerberos delegation, so the double hop (using the session identity to reach a third server) is not solved by it.

## SSH or WinRM

| Need | Prefer |
|---|---|
| Non-domain host, key-based, one port | SSH |
| Domain, Kerberos single sign-on, JEA endpoints | WinRM or PSRP |
| Tools on Linux automation hosts | either; same `pwsh` scripts |

## Worked example: key login falls back to a password

`ssh -v` shows the key offered, then "password" as the only continuation. The OpenSSH event log says `bad ownership or modes for file`. The file inherited read access for Users. Reset with the `icacls` command above. Another cause: a key file written by Windows PowerShell 5.1 with `Out-File` is UTF-16; write it with `-Encoding ascii` or `utf8NoBOM`.

Second failure: `Enter-PSSession` returns `subsystem request failed on channel 0`. The `Subsystem` line used a path with spaces and `sshd` was not restarted. Test the helper with `ssh win01 'pwsh -sshs'`; it should wait silently.

## Security notes

Disable passwords once keys work (`PasswordAuthentication no`), restrict with `AllowGroups`, put the port behind a bastion or VPN, and remember that an SSH session as an administrator gets a full token without a UAC prompt. Windows Update patches the shipped OpenSSH; a second upstream install leaves two `sshd` binaries sharing one configuration directory.

## Common mistakes

- Setting the default shell to `pwsh` and then running scripts that expect `cmd` quoting.
- Quoting a command through three parsers (local shell, remote shell, program); send a script file or `-EncodedCommand` instead.
- Assuming PowerShell 7 is installed on a new Windows Server image; it is not.
