## What strict mode does

```bash
#!/usr/bin/env bash
set -euo pipefail
IFS=$'\n\t'    # optional: narrower word splitting
```

`-e` exits when a simple command fails, `-u` makes an unset variable an error and `pipefail` makes a pipeline fail if any stage fails. The limits matter: `-e` is ignored in conditions (`if cmd`, `cmd || x`, `cmd && x`) and inside functions called from them, and `cmd | head -1` can fail with SIGPIPE under `pipefail`. Treat strict mode as a safety net, not as error handling; check the commands that can reasonably fail.

## Quoting rules

Unquoted expansions undergo word splitting and pathname expansion. Quote `"$var"`, `"$(cmd)"` and `"${arr[@]}"`; leave unquoted only when you want splitting. Use single quotes for text that must stay literal. A glob belongs outside the quotes (`"$dir"/*.log`), and a name that may start with a dash needs `--` or a `./` prefix.

```bash
rm -- "$file"
cp -- "$src" "$dst"/
printf '%s\n' "$name"          # not echo, which treats some names as options
files=(./*.log); [ -e "${files[0]}" ] || exit 0
```

## ShellCheck

`shellcheck script.sh` reports findings with codes such as SC2086 (unquoted variable), SC2046 (unquoted command substitution), SC2155 (declare and assign in one step hides the status) and SC2164 (`cd` without a check). `-S warning` hides style notes, `-x` follows `source` lines, `-s bash` sets the dialect when there is no shebang, and `-f diff` prints a patch. Silence a single finding with a comment, and say why:

```bash
# shellcheck disable=SC2034  # used by the sourced file
```

Run it in CI and in an editor so findings appear while you write. Do not disable codes globally to get green.

## Common failure patterns

| Symptom | Likely cause | First thing to check |
|---|---|---|
| Script continues after an error | the failing command is inside `if` or `||` | where the command sits, `set -x` |
| Exit 141 in a pipeline | SIGPIPE under `pipefail` | `${PIPESTATUS[@]}` |
| `unbound variable` on optional input | `-u` with an unset name | use `${var:-}` where empty is fine |
| `-rf` file treated as an option | missing `--` | quote and add `--` |
