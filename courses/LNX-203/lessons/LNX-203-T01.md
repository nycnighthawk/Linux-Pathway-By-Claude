## What you will be able to do

## Tests and exit status

Every command ends with a status, 0 for success, and `if`, `while`, `&&` and `||` act on it. `[ ... ]` is an ordinary command (also built in), so its operands must be quoted and separated by spaces. `[[ ... ]]` is a keyword: it does not split or glob its operands, supports `==` with patterns, `=~` with a regular expression and `&&`/`||` inside. `(( ... ))` does integer arithmetic and is true when the result is non-zero.

```bash
if [ -r "$file" ] && [ "$n" -gt 3 ]; then echo ok; fi
if [[ $name == *.log && $name != .* ]]; then echo logfile; fi
if (( count % 2 == 0 )); then echo even; fi
[[ $line =~ ^([a-z]+)=(.*)$ ]] && key=${BASH_REMATCH[1]} val=${BASH_REMATCH[2]}
```

## Loops that survive awkward input

```bash
shopt -s nullglob dotglob
for f in ./*.txt; do ...; done                 # a glob, never $(ls)
while IFS= read -r line; do ...; done < file   # one line at a time, no trimming, no backslash handling
while IFS= read -r -d '' f; do ...; done < <(find . -type f -print0)
for arg in "$@"; do ...; done                  # every argument as given
```

A pipe into `while` runs the loop in a subshell, so variables set inside are lost; use redirection or process substitution instead. Associative arrays (`declare -A`) and indexed arrays (`"${arr[@]}"`) cover counting and grouping.

## Parameter expansion and functions

`${var:-default}`, `${var:?message}`, `${file%.*}` (drop a suffix), `${file##*/}` (drop a path), `${var^^}` (upper case) and `${#var}` replace many `sed` and `basename` calls. Functions take positional arguments, use `local` for their variables and return a status with `return N`; their output is captured with `$(...)`.

```bash
die() { printf '%s\n' "$*" >&2; exit 1; }
is_dir() { [ -d "$1" ] || die "not a directory: $1"; }
```

## Cleanup with traps

```bash
tmp=$(mktemp -d) || exit 1
trap 'rm -rf -- "$tmp"' EXIT
trap 'exit 130' INT TERM
```

The `EXIT` trap runs on normal exit, on `exit` and after a fatal error under `set -e`; signal traps that call `exit` make it run for Ctrl-C as well. Use `mktemp`, never a fixed name in `/tmp`.

## Common failure patterns

| Symptom | Likely cause | First thing to check |
|---|---|---|
| `[: too many arguments` | unquoted variable that split | quote every expansion in `[ ]` |
| Counter is 0 after the loop | the loop ran in a pipeline subshell | use `< <(cmd)` or a redirect |
| Names with spaces break | `for f in $(ls)` | switch to a glob or `-print0` |
| Temp files accumulate | no trap, or the trap was replaced | `trap -p`, one `EXIT` trap per script |
