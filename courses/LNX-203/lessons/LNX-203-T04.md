## awk

An awk program is a list of `pattern { action }` pairs run for every input line. Fields are `$1`..`$NF`, `$0` is the line, `NR` the line number and `FS` the input separator (`-F:` sets it). `BEGIN` runs before input and `END` after it. Arrays are associative and created on first use; `for (k in a)` visits keys in no fixed order, so pipe through `sort` when order matters.

```bash
awk 'NR > 1 { cpu[$1] += $3 } END { for (u in cpu) printf "%s %.1f\n", u, cpu[u] }' ps.txt | sort
awk -F: '$3 >= 1000 && $7 !~ /nologin$/ { print $1 }' /etc/passwd
awk -v min=80 '$5+0 >= min { print $6, $5 }' df.txt
```

Pass shell values with `-v name=value`, not by splicing them into the program text. POSIX awk, mawk and gawk agree on this core; gawk adds `asort`, `gensub`, `strftime` and `--csv` in recent versions, so state which awk a script needs.

## jq

A jq program is a filter applied to each JSON input. `.a.b` descends, `.[]` iterates, `|` chains, `select(cond)` filters, `map(f)` applies to each array element, `sort_by(f)`, `group_by(f)`, `length`, `add` and `unique` aggregate, and `"\(.name)\t\(.size)"` builds strings. `-r` prints raw strings, `-c` prints one object per line, `-e` sets the exit status from the last output and `-s` slurps all inputs into one array.

```bash
jq -r '.hosts[] | select(.tags | index("prod")) | .name' inventory.json
jq -r --arg role "$role" '.hosts[] | select(.role == $role) | .name' inventory.json
jq --argjson n 100 '[.hosts[] | select(.disk_gb >= $n)] | length' inventory.json
```

Never build a filter by pasting a shell variable into it: a value containing a quote changes the program. `--arg` passes a string, `--argjson` a JSON value and `--args` collects positional arguments into `$ARGS.positional`.

## Two programs named yq

The Go program by Mike Farah (`yq e '.a.b' file.yaml`, `-i` for in-place edits) has its own expression language modelled on jq. The Python program by Andrey Kislyuk (in the `yq` package) is a wrapper that converts YAML to JSON, runs jq and converts back, so it takes jq programs (`yq -r '.a.b' file.yaml`). Run `yq --version` to see which one you have, and name the one you need in the script's requirements.

## Common failure patterns

| Symptom | Likely cause | First thing to check |
|---|---|---|
| awk prints nothing | wrong field separator or the header consumed the match | print `$0` and `NF` for the first lines |
| Totals are off | text compared as strings, or a header row summed | add `+0`, skip `NR == 1` |
| `jq: error: ... cannot be parsed` | shell quoting broke the filter | put the filter in single quotes or a file with `-f` |
| `yq` flags rejected | the other `yq` is installed | `yq --version` |
