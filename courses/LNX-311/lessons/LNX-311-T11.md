## The bargain

The provider runs API servers and etcd (replicated, patched, backed up) and sells an availability target for the control plane. You still own: worker nodes (to a degree set by the mode), workloads, RBAC, Secrets handling, network design, cost, and backups of your *data*. You cannot SSH to the control plane or change API server flags. Audit and control-plane logs are usually off until you enable them.

## Node models

| Model | Who patches the machine | Typical limits |
|---|---|---|
| Managed node group or pool | provider supplies the image, you roll updates | you size and schedule |
| Bring your own nodes | you | you carry self-managed duties |
| Serverless pods (Fargate, Autopilot pods) | provider | restrictions on privileged pods, host access, DaemonSets |
| Auto modes (EKS Auto Mode, AKS Automatic, GKE Autopilot) | provider | fewer knobs, bundled add-ons |

## Identity

People: the cloud's identity (IAM principals mapped by access entries on EKS, Entra ID groups on AKS, Google identities on GKE) through a **client-go credential plugin**, which is why the provider CLI must be installed. Authorisation remains Kubernetes RBAC. Workloads: **workload identity** (IRSA or Pod Identity, Entra Workload ID, GKE Workload Identity) exchanges a projected service-account token for short-lived cloud credentials. Block pod access to the instance metadata endpoint, or a pod can use the node's role.

## Integrations and limits

A `LoadBalancer` Service makes the cloud controller create a cloud load balancer; annotations are provider-specific. Block volumes are zonal. Pod networking may use VPC addresses (limits pods per node and consumes subnets). Check the provider's support calendar: roughly 14 months of standard support per minor, with paid or longer extended options that differ per provider (verify on the provider pages). Upgrades roll nodes and honour PodDisruptionBudgets.

## Worked example: a public endpoint

CI needed to deploy, so the API endpoint was opened to the internet with no source range, and probing appeared in the audit log. Restrict by source range or use a private endpoint plus a runner inside the network.
