# Signals, signalfd and timerfd

This lesson follows the topic synthesis `synth/LNX-320/LNX-320-T05.md`. Which clocks `timerfd` accepts and what the alarm clocks need are kernel-version details (to verify in `man timerfd_create`).

## What you will be able to do

- Write a signal handler that is safe, and know when not to write one.
- Block signals and read them from a `signalfd` inside an `epoll` or `poll` loop.
- Drive periodic work with `timerfd` and interpret the expiration count.
- Avoid the inheritance traps of masks and dispositions.

## The model

A signal interrupts a thread at an arbitrary point to run a handler. Standard signals do not queue: several `SIGCHLD` while blocked give one delivery. `SIGKILL` and `SIGSTOP` cannot be caught or blocked. Real-time signals queue and carry a value.

## Handlers that are safe

Use `sigaction`, not `signal`. In the handler do only async-signal-safe things: set a `volatile sig_atomic_t` flag, write a byte to a pipe, call `_exit`. Never call `printf` or `malloc`. Save and restore `errno` if the handler calls anything. A fault signal like `SIGSEGV` cannot just return, because the faulting instruction runs again.

## Turning signals into input

1. Block the signals with `sigprocmask` (before creating threads, so all inherit the mask).
2. `signalfd(-1, &mask, SFD_NONBLOCK | SFD_CLOEXEC)` gives a descriptor.
3. Add it to `epoll`; read `struct signalfd_siginfo` records when it is readable.

Now ordinary code runs in response: allocate, log, reload configuration. The signals must stay blocked or the default action still happens. A child that execs inherits the blocked mask, so reset it first.

## Timers

`timerfd_create(CLOCK_MONOTONIC, ...)` plus `timerfd_settime` makes a descriptor that becomes readable at expiry. A `read` returns an 8-byte count of expirations since the last read, so missed ticks are visible. Use the monotonic clock for intervals and the real-time clock with `TFD_TIMER_ABSTIME` for calendar events. `SIGALRM` and `setitimer` give one timer per process and no counts.

## Worked example

A server blocks `SIGTERM`, `SIGHUP` and `SIGCHLD`, adds a `signalfd` and a 10-second `timerfd` to its `epoll` set, and switches on the descriptor. `SIGTERM` starts a graceful stop, `SIGHUP` reloads, `SIGCHLD` runs a `waitpid` loop until it returns 0. The lab builds a small version with `SIGUSR1` and `SIGTERM`.

## What goes wrong

A handler that calls `printf`. One `waitpid` per `SIGCHLD`. A child that cannot be interrupted because it inherited a blocked mask. `EINTR` from `epoll_wait`. A `sleep`-then-repeat loop that drifts.

5. Which clock should an interval timer use?
