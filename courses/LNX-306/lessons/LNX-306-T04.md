# Packer images

This lesson follows the topic synthesis `synth/LNX-306/LNX-306-T04.md`, which carries the sources, the history and the failure cases.

## What you will be able to do

- Read an HCL2 Packer template: plugins, variables, source, build, provisioners, post-processors.
- Make a build repeatable (pinned ISO checksum, plugin versions, dated repository snapshot).
- Generalise an image so that clones get fresh identity, and keep build secrets out of it.
- Test, version, publish and retire images.

## Template anatomy

```
packer { required_plugins { qemu = { version = ">= 1.1.0", source = "github.com/hashicorp/qemu" } } }
variable "ssh_password" { type = string, sensitive = true }
source "qemu" "el9" {
  iso_url = var.iso_url   iso_checksum = var.iso_checksum
  http_directory = "http"         # serves ks.cfg to the installer
  boot_command   = local.kickstart_boot
  ssh_username = "packer"         ssh_password = var.ssh_password
}
build {
  sources = ["source.qemu.el9"]
  provisioner "shell" { script = "scripts/cleanup.sh" }
  post-processor "manifest" { output = "manifest.json" }
}
```

```bash
packer init . ; packer fmt . ; packer validate -var-file=el9.pkrvars.hcl .
PACKER_LOG=1 packer build -on-error=ask .
```

## Generalise before capture

Remove or lock the build user; truncate `/etc/machine-id`; delete SSH host keys; `cloud-init clean --logs --seed`; clear DHCP and network state, logs and history; clean the package cache; trim free space. Skip these and every clone shares an identity.

## Pin and record

ISO with a real `iso_checksum`, plugin versions in `required_plugins`, a dated repository snapshot in the Kickstart, checksummed downloads. Record the Git commit and snapshot in the manifest and in image tags.

## Test, publish, retire

Boot a copy, assert services, open ports, kernel, packages, no build account, distinct host keys on two boots, and the compliance profile. Name images by version and date, keep manifest and checksums beside them, retire old images on a schedule.

## Secrets

`sensitive = true`, `PKR_VAR_...` environment variables or a secrets manager, SSH keys made for the run, isolated build network, a secret scan of the result.

## Worked example: the shared host keys

Images captured without removing host keys made every instance present the same SSH key. Fix: clean-up script, a test that compares fingerprints from two instances, rebuild of the catalogue.
