# NetworkPolicy and L7 CiliumNetworkPolicy

This lesson follows the topic synthesis `synth/LNX-312/LNX-312-T07.md`, which carries the sources, the history and the failure cases.

## What you will be able to do

- Apply the three combination rules of NetworkPolicy and predict the verdict for any flow.
- Build a default-deny baseline with DNS, probe and ingress exceptions.
- Decide when a requirement needs cluster-wide policy or an L7 rule.

## The three rules

1. Policies are additive; there is no order and no deny.
2. A Pod is isolated for a direction once any policy selects it for that direction. Before that it is open.
3. Inside one `from` or `to` element, selectors are AND; separate elements are OR.

```yaml
# one element, AND: monitoring Pods in the monitoring namespace
- from:
  - namespaceSelector: {matchLabels: {kubernetes.io/metadata.name: monitoring}}
    podSelector: {matchLabels: {app: prometheus}}
```

Starting the second selector with its own dash turns the AND into an OR and opens the namespace.

## Baseline for a namespace

Deny both directions for all Pods (`podSelector: {}`, both types, no rules). Then allow, one policy each: ingress from the ingress controller namespace to the web Pods, web to API, API to database, and every Pod to the DNS Pods on port 53 (UDP and TCP). Remember probes and the plugin's own flows when testing.

## Beyond the standard API

| Need | Where |
|---|---|
| Deny a peer, priorities, guardrails | cluster-wide policy (tiers, Allow/Deny/Pass) |
| Match DNS names, entities, host ports | vendor policy (CiliumNetworkPolicy, host policy) |
| Methods and paths | L7 rules via the proxy; scope them narrowly, TLS must be terminated first |

Roll out in audit mode, read the flow log for would-be drops, then enforce.

## Worked example: everything broke after deny-all

Egress default-deny without a DNS allowance makes every name lookup time out. The symptom is application errors, not network errors. Add the DNS egress rule, test from a client Pod, and keep a CI table of allowed and denied flows.
