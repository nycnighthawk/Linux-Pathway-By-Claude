## Ingress in one screen

A rule has a host and paths; each path has a type (Exact, Prefix, ImplementationSpecific) and a backend Service port. A TLS block names a Secret. The `ingressClassName` selects the controller. Nothing happens without a controller, and the API is frozen: features go to the Gateway API.

## Gateway API in one screen

| Object | Owner | Purpose |
|---|---|---|
| GatewayClass | infrastructure provider | names the controller |
| Gateway | cluster operator | listeners (port, protocol, host, TLS) and which namespaces may attach |
| HTTPRoute, GRPCRoute | application team | matches, filters and weighted backends, attached to a Gateway |
| ReferenceGrant | the namespace being referenced | allows a cross-namespace reference to a Service or Secret |

Routes report status per parent: Accepted, ResolvedRefs, Programmed. Read the reason there first.

## Worked example: route attaches to nothing

The HTTPRoute exists, the controller log is quiet, and requests get 404. The route's parent status says NotAllowedByListeners. The Gateway's listener allows routes only from namespaces with a given label. Fix: label the namespace or change `allowedRoutes`. Other causes: wrong parent name, hostname mismatch, missing ReferenceGrant.
