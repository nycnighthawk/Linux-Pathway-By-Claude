## The pipeline

`gcc` and `clang` are drivers. They run the preprocessor, the compiler proper, the assembler and the linker, passing your options to
each. Stop early to inspect a stage: `-E` (preprocessed text), `-S` (assembly), `-c` (object file, no link). Optimisation (`-O0` to `-O3`, `-Os`),
debug data (`-g`), warnings (`-Wall -Wextra`) and the language standard (`-std=c17`) belong to the compile step. Hardening options such as
`-fstack-protector-strong`, `-D_FORTIFY_SOURCE=3` (with optimisation on), `-fPIE` and `-fhardened` (GCC 14 and later) add protections.

## What is inside an ELF file

An object has sections (`.text`, `.data`, `.bss`, `.rodata`), a symbol table and relocation entries. A relocation says: patch the final address of this
symbol here. Linking merges sections, resolves each undefined symbol to a definition and applies the relocations. An executable also carries program
headers: `PT_LOAD` segments the kernel maps, `PT_INTERP` naming the dynamic loader, `PT_DYNAMIC` with `DT_NEEDED`, `DT_SONAME` and `DT_RUNPATH`,
`PT_GNU_STACK` and `PT_GNU_RELRO`. Sections serve the tools, segments serve the kernel and loader.

```bash
nm main.o                 # U = undefined here, T = code defined here
readelf -S -s -r main.o   # sections, symbols, relocations
readelf -lW app           # segments, look for INTERP and GNU_RELRO
readelf -dW app           # dynamic tags: NEEDED, RUNPATH, FLAGS
objdump -d -M intel app | less
```

## Static archives and order

`ar rcs libutil.a util.o` builds an archive. The linker takes a member only if it satisfies a symbol that is undefined at that moment, so list libraries
after the objects that use them: `cc main.o -lutil -lm`. Shared libraries add a `DT_NEEDED` entry instead of copying code (see
[LNX-220-T03](lesson:LNX-220-T03)).

## Hardening and debug files

```bash
cc -O2 -g -fPIE -c main.c
cc -pie -Wl,-z,relro,-z,now -o app main.o
objcopy --only-keep-debug app app.debug
strip --strip-all app
objcopy --add-gnu-debuglink=app.debug app
```

`-pie` lets the kernel randomise the load address, `-z now` resolves every symbol before `main` so `-z relro` can make the table read-only. Keep
`app.debug` (or a build-ID matched debuginfo package) for later debugging, as in [LNX-220-T04](lesson:LNX-220-T04).

## Worked example: an undefined reference

`cc -lm main.c` fails with an undefined reference to `sqrt` on toolchains that use `--as-needed`. Run `nm main.o | grep ' U '` to see what the
object needs, then move the library after the object: `cc main.c -lm`. If a binary built elsewhere refuses to start with a missing `GLIBC_2.xx` version,
`objdump -T app | grep GLIBC_` lists the versions it needs; build on an older base or in a matching container.
