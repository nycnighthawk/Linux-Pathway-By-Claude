# Character devices, file_operations, ioctl

This lesson follows the topic synthesis `synth/LNX-331/LNX-331-T01.md`. Registration helpers and field names change across kernel versions (to verify against your tree).

## What you will be able to do

- Register a misc character device and write its `file_operations`.
- Implement `read`, `write` and `ioctl` with correct return values and user-pointer handling.
- Define ioctl numbers with `_IO*` macros and keep them ABI-safe.
- Support blocking, non-blocking and `poll`.

## The skeleton

```c
static const struct file_operations my_fops = {
	.owner          = THIS_MODULE,
	.open           = my_open,
	.release        = my_release,
	.read           = my_read,
	.write          = my_write,
	.unlocked_ioctl = my_ioctl,
	.poll           = my_poll,
};
static struct miscdevice my_misc = {
	.minor = MISC_DYNAMIC_MINOR,
	.name  = "mydev",
	.fops  = &my_fops,
};
/* init: misc_register(&my_misc);  exit: misc_deregister(&my_misc); */
```

## read and write rules

| Situation | Return |
|---|---|
| bytes transferred | the count (may be less than asked) |
| end of data | `0` |
| nothing yet, `O_NONBLOCK` | `-EAGAIN` |
| nothing yet, blocking | sleep with `wait_event_interruptible`; `-ERESTARTSYS` on a signal |
| bad user pointer | `-EFAULT` |
| device full | `-ENOSPC` |

`copy_to_user` and `copy_from_user` return the bytes **not** copied. Never dereference a `__user` pointer directly. Advance `*ppos` for buffer-like devices.

## ioctl

```c
#define MY_GET_LEN _IOR('k', 1, int)
#define MY_RESET   _IO('k', 2)
#define MY_SET_MAX _IOW('k', 3, int)
```

The macros encode direction, size, type and number. In the handler: switch on `cmd`, validate each value, `-ENOTTY` for unknown commands, `-EINVAL` for bad arguments, `-EFAULT` for bad pointers. Use fixed-width types and explicit padding; add `compat_ioctl` or design so 32-bit callers see the same layout. A released command number is ABI forever.

## Concurrency

Several processes may call at once, so protect shared state, usually with a mutex (handlers may sleep). Count references so removal cannot free state under a running call.

## When not to use ioctl

Simple values: sysfs. Structured configuration: netlink. High-rate submission: io_uring commands.
