# Milestone 5: running on a real development board

This milestone follows the topic synthesis `synth/LNX-404/LNX-404-T05.md`. Versions and defaults change; confirm them in current project documents (to verify).

## Goal

Boot your kernel on a physical board and test your change there.

## Lessons this milestone relies on

- LNX-331-T11 and T12 (arm64 cross-build, bring-up on a real board)
- LNX-331-T02 (device model and device tree)
- LNX-330-T02 (Kconfig and cross-compiling)
- LNX-330-T09 (printk and dynamic debug)

## Steps

1. Read the board documentation for voltage levels and the serial pins before connecting anything.
2. Cross-build the kernel and device tree and boot them over the network or from a card.
3. Capture the whole boot log and check that init starts.
4. Run your driver or patch and compare with the emulator.
5. Write down how you recover from a bad kernel.

## Acceptance

- The evidence file passes the check.
- The boot log is saved.
- Every difference from the emulator has a stated cause.

[Grader lab](lab:dev-board-evidence) checks the mechanical parts of this milestone. Passing it is necessary but not enough: the evidence in your repository is what is marked. See the brief for the rubric.
