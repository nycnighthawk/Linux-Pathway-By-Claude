# Milestone 3: bisect and fix a planted regression

This milestone follows the topic synthesis `synth/LNX-404/LNX-404-T03.md`. Versions and defaults change; confirm them in current project documents (to verify).

## Goal

Find the commit that broke a behaviour and fix it with a test.

## Lessons this milestone relies on

- LNX-330-T10 (git bisect a regression)
- LNX-330-T09 (printk, ftrace, KASAN, lockdep)
- LNX-331-T13 (kernel performance regressions)
- LNX-307-T05 (perf and tracing)

## Steps

1. Write a script that boots a kernel in QEMU, runs a small program and returns pass or fail; run it ten times to detect flakiness.
2. Mark good and bad commits and let bisect run the script; use skip for commits that do not build.
3. Read the culprit and reproduce the failure with the smallest case.
4. Write the fix, a regression test and a commit message with a Fixes tag.
5. Re-run the script on the fixed tree.

## Acceptance

- The grader passes on the search logic.
- The bisect log is saved and the number of steps is near log2 of the range.
- The fix has a test that fails before it and passes after it.
