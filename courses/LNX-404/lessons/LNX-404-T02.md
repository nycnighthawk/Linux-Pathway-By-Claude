# Milestone 2: a series that passes checkpatch and boots on two architectures

This milestone follows the topic synthesis `synth/LNX-404/LNX-404-T02.md`. Versions and defaults change; confirm them in current project documents (to verify).

## Goal

Prepare the driver as a series that reviewers can accept mechanically.

## Lessons this milestone relies on

- LNX-330-T02 (Kconfig, cross-compiling)
- LNX-330-T05 (checkpatch, get_maintainer, sparse, Coccinelle)
- LNX-330-T06 (format-patch, b4, send-email)
- LNX-331-T11 (arm64 cross-build, boot on QEMU virt)

## Steps

1. Split the work into small patches, each building and each useful.
2. For each commit, build x86_64 and arm64 and run the style checker; keep a table of results.
3. Boot the final tree in QEMU on both architectures and record the log markers.
4. Write a cover letter that says how it was tested.
5. Run sparse and fix every warning your code adds.

## Acceptance

- The grader passes on your results table.
- `git bisect` could run across the series without a build failure.
- Both boots reach init.
