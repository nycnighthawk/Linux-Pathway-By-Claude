# Milestone 4: a real review cycle on a subsystem list

This milestone follows the topic synthesis `synth/LNX-404/LNX-404-T04.md`. Versions and defaults change; confirm them in current project documents (to verify).

## Goal

Send a small, correct change to the right list and take it through review.

## Lessons this milestone relies on

- LNX-330-T11 (a real upstream review cycle)
- LNX-330-T06 (patch mail and list etiquette)
- LNX-330-T01 (kernel tree, maintainers)
- LNX-332-T12 (upstreaming to KVM and QEMU, as a parallel)

## Steps

1. Pick a modest target in a subsystem that welcomes it; read earlier discussions.
2. Find the maintainers and lists with the lookup script.
3. Send the series with the standard tools; reply inline to each comment; send a revision with a changelog.
4. Record every version and the archive link.
5. Write down what you would do differently.

## Acceptance

- The evidence file passes the check.
- Each review comment has a reply.
- You kept the archive links for every version.
