# Hardware virtualization

This lesson follows the topic synthesis `synth/LNX-332/LNX-332-T01.md`. Cycle costs and CPU generations vary (to verify).

## What you will be able to do

- Explain how VT-x and AMD-V let a guest run natively and return control on chosen events.
- Describe what the VMCS or VMCB holds and what an exit records.
- Explain two-dimensional paging, its cost and what an EPT violation means.
- Check a host for virtualization support and diagnose why it is unavailable.

## Why hardware help

Trap-and-emulate needs every sensitive instruction to be privileged; the original x86 broke that. Binary translation and paravirtualisation worked around it; VT-x and AMD-V (about 2005 to 2006) fixed it in hardware.

## Vocabulary

| Intel | AMD | Meaning |
|---|---|---|
| VMCS | VMCB | per-guest state and controls block |
| VMLAUNCH / VMRESUME | VMRUN | enter the guest |
| VM exit | #VMEXIT | guest to hypervisor |
| EPT | NPT | guest-physical to host-physical tables |

## An exit, step by step

1. The guest executes something the hypervisor chose to intercept.
2. The CPU saves guest state, records the reason and qualification, loads host state.
3. The hypervisor handles it (emulate, fix the mapping, inject an event).
4. It resumes the guest at the next instruction.

## Two-dimensional paging

Each guest-physical address met during the guest's walk is translated by the nested tables. With 4 levels on each side: (4+1) x (4+1) - 1 = 24 reads. Large pages, page-walk caches and VPID/ASID tags reduce the cost.

## Checking a host

```
lscpu | grep Virtualization
grep -E 'vmx|svm' /proc/cpuinfo | head -1
ls -l /dev/kvm
```

No flag: the CPU lacks it or firmware disabled it. Flag but no `/dev/kvm`: module not loaded or another hypervisor holds the feature.

## Self-check

Try each question before you read the answers below.

1. How many memory reads does a full two-dimensional walk with 4-level tables on both sides take?
2. The `vmx` flag is present but `/dev/kvm` is missing. Name two causes.
3. What does a VM exit record for the hypervisor?

### Answers

1. 24: (4+1) x (4+1) - 1.
2. The kvm modules are not loaded, or another hypervisor's driver holds the feature.
3. The exit reason and qualification in the VMCS or VMCB, along with the saved guest state.
