# Patch rings

This lesson follows the topic synthesis `synth/LNX-304/LNX-304-T07.md`, which carries the sources, the history and the failure cases.

## What you will be able to do

- Define patch rings that are representative, respect redundancy and have a soak time.
- Choose health gates and severity deadlines, and automate the stop.
- Track effective patch state (reboots and restarts), not just installed packages.
- Write a rollback rule and an exception rule before they are needed.

## A ring scheme

| Ring | Contents | Share | Soak |
|---|---|---|---|
| 0 | lab and staging | 1 to 2 % | 1 to 2 days |
| 1 | canary: every service tier represented | about 5 % | 2 to 4 days |
| 2 | early production, one failure domain | 20 to 30 % | 3 to 7 days |
| 3 | main production, by failure domain | the rest | per domain |
| 4 | frozen or certified systems, by agreement | varies | with the owner |

Numbers are starting points. Two things matter more: each ring must resemble the rings after it, and no ring may take down both halves of a redundant pair. Patch replicas before primaries.

## Gates and clocks

Gates are automatic stops: update job success, reboot time, error rate and latency against baseline, failed units, agent heartbeats. A slow failure (a leak) needs a longer soak. Severity sets the deadline: actively exploited issues take an expedite path, others follow the cadence. Write the table and who may use the expedite path.

## Mechanics

```bash
dnf updateinfo list security ; dnf upgrade --security
dnf needs-restarting -r ; dnf history undo N ; dnf versionlock add pkg
apt-get -s upgrade ; apt-mark hold pkg ; cat /var/run/reboot-required
```

Effective state means the running kernel equals the installed one and no service maps an old library. Live patching postpones a reboot, it does not remove it. In Ansible, `serial:` and `max_fail_percentage:` express the stop-on-failure rule.

## Rollback and exceptions

Decide beforehand: hold the ring, revert the repository pointer of later rings, revert hosts (storage snapshot, `dnf history undo`, image rollback) or fix forward. Name who decides and within what time. Test it on ring 0. Exceptions get an owner, a reason, compensating controls and an expiry date.

## Worked example: the representative canary

A canary of twenty stateless web nodes missed a connection-pool change that only batch servers used. Batch jobs failed fleet-wide on Friday night. The rule that follows: ring 1 contains at least one host of every service tier.
