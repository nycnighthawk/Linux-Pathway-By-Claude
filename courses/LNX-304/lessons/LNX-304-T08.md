# bootc / image mode, rpm-ostree

This lesson follows the topic synthesis `synth/LNX-304/LNX-304-T08.md`, which carries the sources, the history and the failure cases.

## What you will be able to do

- Explain the filesystem contract of an image-based system: `/usr`, `/etc` and `/var`.
- Write a bootc `Containerfile` and say what belongs in the image and what does not.
- Upgrade, switch and roll back a host with `bootc` and `rpm-ostree`.
- Place ring promotion, signing and health checks around an image pipeline.

## The contract

| Path | Behaviour |
|---|---|
| `/usr` | read-only, comes from the image |
| `/etc` | writable; on update a three-way merge keeps local edits and adds new defaults |
| `/var` | writable and persistent; the image does not overwrite existing data |

Updates are transactional: the new deployment is staged complete and used at the next reboot; the old one stays as the rollback entry.

## Build

```
FROM registry.example.org/base/rhel10-bootc:10.0
RUN dnf -y install chrony tmux && dnf clean all
COPY 10-site.toml /usr/lib/bootc/kargs.d/10-site.toml
RUN systemctl enable chronyd.service
RUN bootc container lint
```

```bash
podman build -t registry.example.org/site/el10:2026-11-08 .
bootc-image-builder ...        # image to qcow2, ISO or AMI
bootc status ; bootc upgrade --apply ; bootc switch registry.example.org/site/el10:stable
bootc rollback ; rpm-ostree status ; rpm-ostree kargs --append=audit=1
```

Kernel arguments go in `kargs.d` TOML drop-ins. A fix made on one host with `rpm-ostree usroverlay` is temporary: write it into the `Containerfile`.

## Operate

Tags move through rings (`candidate` then `stable`); digests are immutable. Sign images, attach an SBOM and provenance, and make hosts refuse unsigned images. Health checks (greenboot) after boot trigger automatic rollback. Apply hardening at build time and scan the built image. Never bake secrets into an image.

## Worked example: the lost `/etc` edit

A build step edited a shared `/etc` file that hosts also change locally. After an update the host's copy wins and the fleet diverges. Ship settings as drop-ins that the application reads.
