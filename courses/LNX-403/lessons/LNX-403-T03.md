# Milestone 3: packages in four formats

This milestone follows the topic synthesis `synth/LNX-403/LNX-403-T03.md`. Versions and defaults change; confirm them in current project documents (to verify).

## Goal

Build and publish the service as an RPM, a DEB, a Flatpak and an OCI image from one version.

## Lessons this milestone relies on

- LNX-220-T10 (packaging apps: RPM, DEB, Flatpak, OCI)
- LNX-304-T01 to T03 (RPM, DEB, signing)
- LNX-310-T05 and T08 (Containerfile craft, supply chain)
- LNX-220-T07 (toolchains for other languages)

## Steps

1. Keep one VERSION source and generate or check the other four places from it.
2. Write the spec, the debian directory, the manifest and the Containerfile.
3. Build each in a clean environment in CI (mock, sbuild, flatpak-builder, buildah).
4. Sign the packages and the image; publish checksums.
5. Install each on a clean system and run the service.

## Acceptance

- The grader passes on the metadata files.
- All four artefacts install and run on clean systems.
- A release script fails when versions disagree.
