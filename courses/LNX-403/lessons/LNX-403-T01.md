# Milestone 1: an epoll daemon with sd_notify and socket activation

This milestone follows the topic synthesis `synth/LNX-403/LNX-403-T01.md`. Versions and defaults change; confirm them in current project documents (to verify).

## Goal

Write the service itself in C or Rust and run it under systemd with a socket unit.

## Lessons this milestone relies on

- LNX-320-T03 (epoll and io_uring)
- LNX-320-T05 and T08 (signals, sockets and non-blocking servers)
- LNX-220-T08 (systemd integration: sd_notify, socket activation, journald)
- LNX-220-T01 to T03 (toolchain and libraries)

## Steps

1. Define the protocol of your service and write its tests first.
2. Implement the accept and read loop on epoll, non-blocking, edge or level triggered as you choose and justify.
3. Adopt the listening socket from the environment and send readiness after registration.
4. Handle termination through the event loop and exit with status zero.
5. Run it under a socket unit and show that a connection during restart is not refused.

## Acceptance

- The grader passes on the model daemon.
- Your real daemon serves two hundred clients from one thread in a test.
- A restart under load drops no connections in your test.
