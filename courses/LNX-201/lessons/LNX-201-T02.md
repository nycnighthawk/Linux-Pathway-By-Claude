# ip, ss and ethtool

This lesson follows the topic synthesis `synth/LNX-201/LNX-201-T02.md`, which carries the sources and the history.

## What you will be able to do

- Read the state of links, addresses, routes and neighbours with `ip`.
- Find which process listens on or uses a port with `ss`.
- Read and change NIC settings with `ethtool`, knowing which changes survive a reboot.

## ip

`ip` replaces `ifconfig`, `route` and `arp`. Objects: `link`, `addr`, `route`, `neigh`, `rule`, `netns`. Useful forms:

```bash
ip -br link               # one line per interface: name, state, MAC
ip -br addr               # addresses per interface
ip -s link show eth0      # statistics: errors, drops, overruns
ip route show             # main routing table
ip route get 192.0.2.10   # which route, interface and source address would be used
ip neigh show             # ARP / neighbour cache and its states
ip -j addr show lo        # JSON output for scripts (-j), -p pretty-prints it
```

Changes made with `ip addr add`, `ip link set` and `ip route add` apply at once and vanish at reboot. Persistent
configuration belongs to NetworkManager, systemd-networkd or netplan (next topics). Neighbour states: REACHABLE,
STALE (to be revalidated), DELAY, PROBE and FAILED (nothing answered).

## ss

`ss` reads sockets from the kernel. Flags combine: `-t` TCP, `-u` UDP, `-l` listening, `-n` numeric, `-p` processes
(needs privilege to see other users), `-a` all, `-i` TCP internals, `-s` summary, `-4` or `-6` one family.

```bash
ss -ltnp                       # who listens on which TCP port
ss -tn state established '( dport = :443 )'
ss -tnp dst 192.0.2.10         # connections to one host
ss -ti dst 192.0.2.10          # rtt, congestion window, retransmissions
```

A listener bound to `127.0.0.1` is reachable only locally; `0.0.0.0` or `[::]` means every address; `*` means any.

## ethtool

`ethtool eth0` shows speed, duplex and link detection. `ethtool -i` names the driver and firmware, `-S` prints NIC
statistics, `-k` lists offload features (`-K eth0 gro off` toggles one), `-g` and `-G` show and set ring sizes,
`-a` shows pause settings. All changes are runtime only. To persist them use a NetworkManager setting or a udev or
systemd link file; a hand-written `ethtool` line in a boot script is a last resort.

## Common failure patterns

| Symptom | Likely cause | First thing to check |
|---|---|---|
| `ip` shows an address but no traffic | link down or no carrier | `ip -br link`, `ethtool eth0` |
| Service "up" but unreachable | bound to loopback only | `ss -ltnp` local address column |
| Many drops on one NIC | ring too small or offload bug | `ethtool -S`, `ip -s link` |
| Setting gone after reboot | runtime-only change | the persistent configuration |
