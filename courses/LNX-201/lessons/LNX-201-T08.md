## The ladder

1. Link: `ip -br link`, `ethtool`.  2. Address: `ip -br addr`.  3. Gateway: `ip route show default`, `ping`, `ip neigh`.
4. Route: `ip route get`.  5. Outside address: `ping 1.1.1.1`.  6. Names: `getent hosts`, `dig`.
7. Service: `ss -tlnp` on the server, `nc -zv` or `curl -v` from the client.  8. Firewall: `nft list ruleset`, `firewall-cmd --list-all`.
The first failing step is where to look. Change one thing, retest, record.

## mtr

```bash
mtr -rwn -c 100 example.com        # report, wide, numeric, 100 cycles
mtr -rn -T -P 443 -c 100 host      # TCP SYN probes to port 443
```

Columns: `Loss%`, `Snt`, `Last`, `Avg`, `Best`, `Wrst`, `StDev`. Loss only on a middle hop with none after it is ICMP rate limiting. Loss that
continues to the last hop is real. A jump in latency that persists marks where delay is added. One trace shows one direction.

## dig

```bash
dig +short example.com A
dig @192.0.2.53 example.com AAAA
dig +trace example.com
dig +norecurse @ns1.example.net example.com SOA
```

Header `status`: `NOERROR`, `NXDOMAIN`, `SERVFAIL`, `REFUSED`. Flags: `rd` recursion desired, `ra` recursion available, `aa` authoritative,
`ad` DNSSEC validated. A reply without `aa` came from a cache; the TTL column shows its remaining life.

## tcpdump

```bash
tcpdump -i eth0 -nn host 192.0.2.10 and port 443
tcpdump -i eth0 -nn -s 0 -w web.pcap port 80
tcpdump -nn -r web.pcap 'tcp[tcpflags] & tcp-rst != 0'
```

`-n`/`-nn` skip name lookups, `-c` stops after N packets, `-w` writes a pcap, `-r` reads one, `-e` shows link-level headers.
SYN with no answer: dropped or lost. SYN then RST: nothing listening or a reject rule. Capture at both ends and compare.

## Common failure patterns

| Symptom | Likely cause | First thing to check |
|---|---|---|
| Small packets pass, large hang | MTU black hole | `ping -M do -s 1472` |
| Name fails for apps only | switch order or hosts | `getent hosts`, `nsswitch.conf` |
| SYNs repeat without reply | drop rule or lost path | capture on both ends |
| Loss on one hop only | ICMP rate limit | the last hop's loss |
