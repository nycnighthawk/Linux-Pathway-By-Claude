## [](#NAME)NAME

           system-config-selinux - SELinux Management tool

## [](#SYNOPSIS)SYNOPSIS

           system-config-selinux

## [](#DESCRIPTION)DESCRIPTION

           system-config-selinux provides a graphical interface for managing
           the SELinux configuration.

## [](#OPTIONS)OPTIONS

           None

## [](#FILES)FILES

           /usr/bin/system-config-selinux

## [](#Examples)Examples

           To run the program type:

           system-config-selinux

## [](#SEE_ALSO)SEE ALSO

           selinux(1),
                  semanage(8)
