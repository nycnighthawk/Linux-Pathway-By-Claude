## [](#NAME)NAME

           sepolicy-gui - Graphical User Interface for SELinux policy.

## [](#SYNOPSIS)SYNOPSIS

           Common options

           sepolicy gui [-h ] [ -d DOMAIN ]

## [](#DESCRIPTION)DESCRIPTION

           Use sepolicy gui to run the graphical user interface, which allows
           you to explore how SELinux confines different process domains.

## [](#OPTIONS)OPTIONS

           -h, --help
                  Display help message

           -d, --domain
                  Initialize gui to the selected domain
