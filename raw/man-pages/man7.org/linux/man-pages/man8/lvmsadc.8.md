## [](#NAME)NAME

           lvmsadc — LVM system activity data collector

## [](#SYNOPSIS)SYNOPSIS

           lvmsadc

## [](#DESCRIPTION)DESCRIPTION

           lvmsadc is not supported under LVM2. The device-mapper statistics
           facility provides similar performance metrics using the dmstats(8)
           command.

## [](#SEE_ALSO)SEE ALSO

           dmstats(8), lvm(8)
