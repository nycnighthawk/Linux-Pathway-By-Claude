## [](#NAME)NAME

           selinux-polgengui - SELinux Policy Generation Tool

## [](#SYNOPSIS)SYNOPSIS

           selinux-polgengui

## [](#DESCRIPTION)DESCRIPTION

           selinux-polgengui is a graphical tool, which can be used to create
           a framework for building SELinux Policy.

## [](#OPTIONS)OPTIONS

           None

## [](#FILES)FILES

           /usr/bin/selinux-polgengui

## [](#Examples)Examples

           To run the program type:

           selinux-polgengui
