    GETKEYCODES(8)           System Manager's Manual           GETKEYCODES(8)

## [](#NAME)NAME

           getkeycodes - print kernel scancode-to-keycode mapping table

## [](#SYNOPSIS)SYNOPSIS

           getkeycodes [options]

## [](#DESCRIPTION)DESCRIPTION

           The getkeycodes command prints the kernel scancode-to-keycode
           mapping table.

## [](#OPTIONS)OPTIONS

           -V, --version
                  print version number;

           -h, --help
                  print this usage message.

## [](#SEE_ALSO)SEE ALSO

           setkeycodes(8)
