    LOGNAME(1)                    User Commands                    LOGNAME(1)

## [](#NAME)NAME

           logname - print user´s login name

## [](#SYNOPSIS)SYNOPSIS

           logname [OPTION]

## [](#DESCRIPTION)DESCRIPTION

           Print the user's login name.

           --help display this help and exit

           --version
                  output version information and exit
