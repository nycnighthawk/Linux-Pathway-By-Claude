    PSLOG(1)                   Linux User's Manual                   PSLOG(1)

## [](#NAME)NAME

           pslog - report current logs path of a process

## [](#SYNOPSIS)SYNOPSIS

           pslog pid ...
           pslog -V

## [](#DESCRIPTION)DESCRIPTION

           The pslog command reports the current working logs of a process.

## [](#OPTIONS)OPTIONS

           -V     Display version information.

## [](#SEE_ALSO)SEE ALSO

           pgrep(1), ps(1), pwdx(1).
