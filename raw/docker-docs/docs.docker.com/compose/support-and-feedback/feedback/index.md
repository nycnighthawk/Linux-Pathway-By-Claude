There are many ways you can provide feedback on Docker Compose.

### [Report bugs or problems on GitHub](#report-bugs-or-problems-on-github) {#report-bugs-or-problems-on-github .scroll-mt-20 .flex .items-center .gap-2}

To report bugs or problems, visit [Docker Compose on GitHub](https://github.com/docker/compose/issues)

### [Feedback via Community Slack channels](#feedback-via-community-slack-channels) {#feedback-via-community-slack-channels .scroll-mt-20 .flex .items-center .gap-2}

You can also provide feedback through the `#docker-compose` [Docker Community Slack](https://dockr.ly/comm-slack) channel.
