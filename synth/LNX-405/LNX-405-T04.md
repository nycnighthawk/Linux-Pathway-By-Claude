# VFIO passthrough of a real device

## Define the problem

Some guests need direct access to a physical device: a network card for line-rate packet processing, a graphics card or an accelerator. Emulation or virtio cannot give full device features or speed. The problem is to hand a real PCI device to a virtual machine safely, so that the guest drives it directly while the host keeps memory isolation through the IOMMU.

## History and approaches

Early passthrough lacked isolation, so a guest could use the device's direct memory access to read host memory. IOMMUs (Intel VT-d, AMD-Vi) translate and restrict device accesses, and the Linux VFIO framework exposes devices to user space in IOMMU groups with the isolation guaranteed. SR-IOV adds virtual functions that can be assigned individually.

## Current state

The host enables the IOMMU, finds the device's IOMMU group, unbinds the device from its native driver and binds it to the vfio-pci driver. The VMM opens the group and maps guest memory for device access. The guest loads its own driver and uses the device. All devices in the same group must be assigned together, so group layout matters. Reset support, interrupt remapping and firmware settings determine whether this works.

## Assessment: the good, the bad and the ugly

Passthrough gives near-native device performance. Costs: the device is unavailable to the host, live migration is difficult, groups can force awkward choices, and some devices do not reset cleanly. Graphics cards add driver hurdles. The ugly part is variability between hardware: the same steps work on one board and not another.

## Applications beyond this domain

The same mechanism supports user-space drivers (DPDK, SPDK) and confidential device assignment.

## Examples

A worked example: a network card in its own IOMMU group is bound to vfio-pci and given to a guest, which reports its ethernet speed and passes traffic. A failing example: a card shared its group with a bridge and a second device; the pass-through failed until all members were assigned or an ACS override (with its security cost) was used.
