Course Build Playbook

Ready-to-paste prompts and a three-worker board for building all courses end to end: finish curating raw sources, write original syntheses, then produce browser-ready courses with lessons, quizzes and CI-graded labs. Repo: nycnighthawk/Linux-Pathway-By-Claude.

1 · Start the project

Three steps. Create a project on the repo with your GitHub-connected environment, upload this file to the project's Library, and paste the Start prompt into the project conversation. The coordinator copies the project instructions into settings itself, runs at most three worker threads, merges green PRs, and picks up again by itself when a usage limit resets.

CurateSources, tagging, certification objective maps
SynthesizeOne original synthesis per topic, synth check passing
ProduceLessons, quizzes, labs with graders, course site pages
ReleaseLink and accessibility checks, Pages deploy

2 · Worker board

The project tracks its own progress from GitHub. Use this board to see the plan's order and dependencies, or to run threads by hand: Fill next slot picks the first item whose dependencies are merged and shows its prompt. Progress here is kept in this browser only.
