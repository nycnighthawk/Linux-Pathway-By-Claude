Course Build Playbook

Ready-to-paste prompts and a three-worker board for building all courses end to end: finish curating raw sources, write original syntheses, then produce browser-ready courses with lessons, quizzes and CI-graded labs. Repo: nycnighthawk/Linux-Pathway-By-Claude.

1 · Set up the project

Paste the first prompt into the project's Instructions and the second as the first message to the coordinator. Every course moves through the same pipeline, and at most three worker threads run at once.

CurateSources, tagging, certification objective maps
SynthesizeOne original synthesis per topic, synth check passing
ProduceLessons, quizzes, labs with graders, course site pages
ReleaseLink and accessibility checks, Pages deploy

2 · Worker board

Three slots, one per worker thread. Fill next slot picks the first work item whose dependencies are merged and shows its prompt. Paste it to the coordinator, then record the PR and the merge here. Progress is kept in this browser only.

Lab envs: C container, V nested KVM VM, W Windows runner (graded in CI); S self-hosted, K cloud, H hardware, O time or human (manual guides).

3 · Prompt library

Every worker prompt, with a course picker where the prompt is per course. The board fills these in for you; use the library to re-run or adapt one.

4 · Steering

Short prompts for the coordinator while the build runs.
